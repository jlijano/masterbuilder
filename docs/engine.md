# Engine

The editor engine package owns deterministic build-mode logic that should be
testable outside React and Three.js.

## Planned Areas

- Snapping and alignment guides
- Wall and room tools
- Measurements
- Selection and multi-selection
- Undo and redo
- Scene graph serialization
- Object registry

## Phase 1 Status

The package boundary exists with initial feature flag contracts. Full geometry
systems and unit tests are scheduled for Phase 5.
