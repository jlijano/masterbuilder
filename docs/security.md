# Security

Security starts with safe defaults and clear boundaries.

## Current Foundations

- No production secrets are committed.
- Environment examples use safe placeholders.
- API CORS is configurable.
- Nest validation pipe is enabled.
- Upload size and provider variables are declared for future implementation.

## Planned Hardening

- Authentication provider integration.
- Role-aware authorization guards.
- Project ownership and team membership checks.
- Upload MIME and size enforcement.
- Rate limiting and secure headers.
- Dependency audit workflow review.
